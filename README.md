# Recortador 9:16 / 4:5

Recortador de fotos en batch para Stories/Reels (9:16) y Feed (4:5). Corre 100% en el navegador (sin backend): drag & drop, efectos de color, reposicionamiento de recorte, mejora de nitidez con canvas, y export en ZIP.

## Uso local

Abrí `index.html` en el navegador, o servilo con cualquier servidor estático:

```bash
npx serve .
```

## Deploy en Vercel

Este es un sitio estático (un solo `index.html`), así que no necesita build ni configuración: solo hay que importar el repo en [vercel.com/new](https://vercel.com/new) y Vercel lo detecta automáticamente.
